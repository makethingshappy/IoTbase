# SKU — IoTbase PICO

```
020215vvvblp
```

| Field | Description |
|---|---|
| `020215` | Product code — IoTbase PICO |
| `vvv` | Version (e.g. 305 = version 3.05) |
| `b` | Bus |
| `l` | Level |
| `p` | Power |

**Bus (b):**

| Value | Description |
|---|---|
| 0 | No |
| 1 | RS485 |
| 2 | 1-Wire |
| 3 | RS485 & 1-Wire |
| 6 | mikroBUS |
| 7 | mikroBUS & RS485 |
| 8 | mikroBUS & 1-Wire |
| 9 | mikroBUS & RS485 & 1-Wire |

**Level (l):**

| Value | Description |
|---|---|
| 1 | BASIC |
| 2 | STD |
| 3 | EXT |

**Power (p):**

| Value | Description |
|---|---|
| 0 | USB |
| 1 | 5W |
| 2 | 10W |
| 3 | 15W |
