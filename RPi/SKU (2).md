# SKU — IoTbase RPi

```
020201304bep
```

| Field | Description |
|---|---|
| `020201` | Product code — IoTbase RPi |
| `304` | Version (3.04) |
| `b` | Bus |
| `e` | EEPROM |
| `p` | Power |

**Bus (b):**

| Value | Description |
|---|---|
| 0 | No |
| 1 | RS485 |

**EEPROM (e):**

| Value | Description |
|---|---|
| 1 | 8 Kbit |
| 2 | 64 Kbit |

**Power (p):**

| Value | Description |
|---|---|
| 0 | USB |
| 1 | 5W |
| 2 | 10W |
| 3 | 15W |
